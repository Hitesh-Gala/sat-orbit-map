Every element set NAZAR has held onto, newest first — with the moment it was obtained from Space-Track above each one.
Every other file on this site keeps the newest element set and throws the previous one away. That is why the Cosmos 2612 / ICEYE-X36 rendezvous of 18 October could not be reconstructed here: by the time anyone asked, the only elements on disk were ten days past it and described the orbit Cosmos 2612 left on, not the one it flew. This is the store that fixes it. One element set per object is appended on each daily Space-Track pull, so a newly watched object starts with one row and fills to twenty over about three weeks; where Space-Track's history service allows, the last twenty are also backfilled a few objects at a time.
